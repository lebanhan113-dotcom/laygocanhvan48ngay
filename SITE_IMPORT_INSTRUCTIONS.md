# Easy Peasy English - Buddy | ChatGPT Sites import

This is a compatibility package for ChatGPT Sites (@Sites).

## IMPORTANT: not a complete original website
The source vocabulary for 10 Units (88 original items), original images and Buddy artwork are NOT included. This website is an unpopulated study-engine prototype. DO NOT present it as the original or publish it as a finished learning resource. Preserve any existing live site until the original source is provided and verified.

## Import with ChatGPT Sites
1. Open ChatGPT Work (web or desktop) and invoke @Sites.
2. Attach this ZIP as the site source project and ask ChatGPT Sites to import index.html as the homepage.
3. Ask it to save a private preview first, NOT deploy over the existing Buddy site.
4. Supply the original source HTML/ZIP/Git repository and all images, check 10 Units and 88 entries, audit meanings/IPA/IT/PE and test interactions.
5. Inspect the preview on desktop/mobile, and only then deploy and choose sharing permissions.

## Features included
Five learning stages, guided/listening/picture recall/sentence practice/review, mastery separate from card views, unit quiz, game coverage and results, offline browser localStorage, recording and listening back. Speech recognition confidence is not treated as pronunciation score. No backend or real phoneme-level assessment.
